## 📦 Installation

```bash
pip install pdfjin-ai-contract-auditor
```

Or install from source:

```bash
git clone https://github.com/pdfjin/pdfjin-ai-contract-auditor.git
cd pdfjin-ai-contract-auditor
pip install .
```
